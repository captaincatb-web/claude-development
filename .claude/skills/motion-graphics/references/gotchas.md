# 함정 목록 (gotchas) — 렌더 전에 전부 확인

## 자동 점검으로 잡히는 것
`render.mjs --check` = 린트(아래 금지 패턴) + 결정론(같은 t를 다른 순서로 찍어 비교) + 루프(SCENE.loop) + 페이지 오류.
린트 경고가 의도적이면 해당 줄 끝에 `// lint-ok`.

## 결정론 (녹화가 깨지는 원인 1순위)
- CSS `transition`/`animation`, `setTimeout`/`setInterval`, `Date.now()`, `performance.now()`, `Math.random()`을 장면 코드에서 쓰지 않는다. 모든 값은 `render(t)`가 t로만 계산. 랜덤은 `M.rand(seed)`.
- 시뮬레이션(물리·파티클·반응-확산)은 고정 스텝(1/fps 또는 1/120)으로 t=0부터 적분하고, 상태를 프레임별로 캐시해 `render(t)`가 같은 t에 같은 결과를 내게 한다. 역방향 탐색 시 처음부터 재계산.
- `<video>`를 넣을 때는 `video.currentTime = t`로 맞추고 `seeked` 이벤트까지 기다린다(`__seek`을 확장).
- 폰트 로드 전에 첫 프레임을 찍지 않는다(렌더러가 `document.fonts.ready` 대기). 폰트는 `font-display: block`.
- 부팅 시 레이아웃 측정(`offsetWidth`, `measureText`)은 한 번만 하고 캐시 — 렌더 중 레이아웃 의존 금지.
- WebGL은 `preserveDrawingBuffer: true` 없으면 캡처가 빈 화면.

## 선명도
- 카메라가 스케일하는 요소에 `will-change`를 넣지 않는다 → 텍스트가 흐릿하게 래스터화된다.
- 크게 확대될 요소는 **큰 크기로 만들고 축소**해서 시작한다(작게 만들어 확대하면 뭉갬).
- 서브픽셀 이동으로 정지 텍스트가 떨리면 정지 구간에서 `Math.round()`로 위치 고정.
- `backdrop-filter`는 헤드리스 렌더에서 비싸고 불안정 → 반투명 배경 + 보더로 대체.

## 텍스트
- 모핑하는 컨테이너 안에서 바뀌는 텍스트는 **자체 등장·퇴장 타이밍**을 가져야 한다. 안 그러면 이전/다음 문구가 겹친다(퇴장 끝 → 등장 시작 사이 0.05s 이상 간격).
- `word-break: keep-all`로 한글 단어 중간 줄바꿈 방지. 줄바꿈은 직접 지정.
- 카운트업 숫자는 `tabular-nums` — 자릿수 폭이 흔들리지 않게.
- 화면에 동시에 보이는 글자 수가 많으면 읽을 시간이 없다. 한 장면 헤드라인 ≤ 14자 권장.

## 실제 검수에서 나온 실수 (예제 만들며 잡은 것)
- **absolute 자식의 기준 부모**: `position: relative`가 없는 컨테이너 안의 absolute 하이라이트가 엉뚱한 위치(입력창 위)를 덮었다. 겹치는 배경 요소는 부모를 반드시 positioned로.
- **밝은 강조 띠 위 흰 글자**: 라임/코랄 형광펜이 흰 글자를 덮으면 안 읽힌다 → 띠가 지나가는 동안 글자색을 어둡게 보간.
- **모프 안의 문구**: 행이 패널로 커질 때 원래 문구를 그대로 두면 늘어나며 겹친다 → 모프 시작 전 문구 퇴장, 확장 후 새 내용 등장.
- **박자와 이징 길이 충돌**: 2박(0.94s) 간격인데 등장 0.9s + 퇴장 시작 -0.22s → 단어가 다 서기 전에 가라앉음. 첫 항목은 3박을 주거나 등장 길이를 줄인다.
- **루프 경계 1px 번짐**: 마스크 밖으로 나간 글자의 안티앨리어싱 1px이 t=0과 t=duration에서 달랐다 → 루프 경계 구간에서 장면 컨테이너를 `visibility:hidden`.
- **시뮬레이션 시드 탐색**: 다른 스크립트로 찾은 시드가 페이지에선 다르게 동작(`t += dt` vs `i*dt` 누적 차이). 탐색은 페이지와 **같은 코드**로.
- **선언만 된 폰트 경고**: 쓰지 않은 @font-face는 로드되지 않는 게 정상. 렌더러는 `status === 'error'`인 것만 경고한다.

## 루프
- 마지막 프레임을 첫 프레임과 **동일하게**: 커서 위치와 속도까지. 아니면 루프에서 튄다. `--check`로 검증.
- 루프가 목적이 아니면 마지막 0.3s는 홀드(편집자가 자를 여유).

## 레이아웃
- 비트마다 스틸을 찍어 그리드(여백 80/64px)에서 벗어나거나, 잘리거나, 좁아서 읽기 어려운 것을 고친다.
- 등장 전 요소는 `opacity:0`만이 아니라 화면 밖/마스크 안에 있어야 한다(그림자·보더가 새어 나옴).
- `overflow:hidden` 마스크 + `border-radius` 조합은 하위 transform과 함께 클리핑이 깨질 수 있다 → `clip-path` 사용.

## 화면 재연(UI 데모)
- 가짜 UI는 "설명용 재연"이다. 실제 앱 동작·AI 결과를 보여 줄 땐 직접 녹화/이미지 파일을 슬롯에 넣는다.
- 커서는 직선이 아니라 살짝 휘는 경로(아크) + 목표 직전 감속(`outCubic`) + 클릭 시 0.1s 스케일 0.9 펀치.
- 타이핑은 글자당 0.04–0.07s, 공백·구두점 뒤 약간 더 쉼(사람처럼). 시드 고정 지터.
