# 프롬프트 라이브러리 — CHA Motion Kit 원문

출처: Career Hacker Alex, 「따라 만드는 모션그래픽 172」 (careerhackeralex.com/sharings/cha-motion-kit, 2026.10).
원 사이트 고지: "영상과 프롬프트는 개인 학습·제작에 자유롭게 쓰세요". 아래는 카드 대화상자(`pre#promptText`)의 원문이다.
이 스킬에서는 **구조와 수준의 기준점**으로 쓴다. 새 장면을 설계할 때 가장 가까운 원문을 찾아 같은 밀도(초 단위 비트, 수치, 강조색 1곳, 결정론 조건)로 쓴다.

분석 요약은 `prompt-patterns.md`.

수록: 리믹스 7/7(리소는 일부) · 제너레이티브 5/5 · 타이포 1 · 트랜지션 1 · 화면 속 작업 1 · 창작 변환 2 · 모션 용어 1 + 조합 4. 나머지 카드는 같은 틀을 따른다(`scene-recipes.md`에 카드별 구조 정리).

## 리믹스

### 왜 '한도 도달'이 뜰까 — 토큰 버킷 시뮬레이션 (12초)
```
토큰 버킷 방식의 사용량 한도가 어떻게 동작하는지 실제로 돌려 보여 주는 모션을 HTML 캔버스 + GSAP로 만들어줘. 캔버스 1080×830, 12초.
- 짙은 차콜 #0A0A0A 배경. 위 모서리에 작은 모노 라벨 "CHA · TOKEN BUCKET", "용량 10 · 초당 2개 충전 · 예시 값". 라임 #D4F527은 통 안의 토큰에만.
- 왼쪽: 칸 10개짜리 통. 남은 토큰은 라임 막대, 맨 위 칸은 초당 2개 속도로 연속해서 차오르는 게 보이게 반투명으로 일부만 채운다. 요청이 처리될 때마다 맨 위 토큰 하나가 오른쪽으로 빠져나가며 사라진다. 옆에 큰 숫자로 남은 토큰("7 / 10 토큰").
- 가운데 오른쪽: 요청 기록. 최신이 맨 위에 미끄러져 들어온다. 시각, 요청 번호, 결과(처리 / 거절), 남은 토큰. 거절은 흐리게, 번호에 취소선, "거절"은 빨간 상태색.
- 아래: 0–12초 동안 토큰 수 그래프가 현재 시각까지 그려지고, 그 아래 요청마다 작은 눈금(거절은 빨갛고 길게).
- 시나리오: 0.5–3초 초당 2번(충전이 따라잡음) → 3.3초부터 1.4초 동안 16번 몰림(바닥남) → 4.9–8.6초 초당 4번(절반 거절) → 9초부터 0.9초 간격(회복). 단계마다 위 헤드라인이 바뀐다: "평소엔 충전이 소비를 따라잡고" → "한꺼번에 몰리면 통이 바닥나고" → "빈 통이면 채워질 때까지 거절" → "한도 = 통의 크기 + 채워지는 속도".
요청 목록을 고정해 두고 시간 t까지의 결과를 처음부터 다시 계산해서, 하나의 paused GSAP 타임라인에서 어느 시점을 렌더해도 같은 화면이 나오게.
```

### 끊기지 않는 도형 하나 — UI 상태 10단 모프 (12초)
```
도형 하나가 한 번도 끊기지 않고 UI 상태 10개로 차례로 변하는 모션을 HTML + GSAP로 만들어줘. 캔버스 1080×830, 12초.
- 짙은 차콜 #0A0A0A 배경 가운데에 연한 종이색 #F4F3EE 도형 하나. 크기·모서리·색이 바뀔 뿐 다른 요소로 갈아끼우지 않는다. 라임 #D4F527은 한 장면에 한 곳만.
- 순서: "실행하기" 버튼 → 커서가 클릭 → 원형 로딩 → 라임 원 안에 체크가 그려짐 → 토글(커서가 켜면 트랙이 라임이 되고, 손잡이의 앞쪽 끝이 더 빠른 스프링을 타서 늘어났다 돌아옴) → 긴 슬라이더(커서가 손잡이를 끌면 값이 커서 위치를 따르고, 놓으면 그 자리에서 스프링으로 75%에 정착, 위에 "사용량 75%" 표시) → 일간·주간·월간 탭(선택 표시의 두 끝이 서로 다른 스프링이라 늘어나며 이동) → 차트 카드(선이 그려지고 숫자가 0→128로 올라가며 커서를 따라 툴팁) → ⌘K 검색창이 커지며 "보고서 저장"이 타이핑되고 결과 두 줄 → 어두운 알림 "보고서를 저장했어요"(라임 점) → 다시 버튼.
- 상태마다 카메라가 확대/축소해 도형이 화면을 알맞게 채운다. 내용은 짧은 블러로 바뀐다. 위 모서리에 작은 모노 라벨("CHA · ONE SHAPE, NEVER CUT", "03 / 10 · 완료").
- 스프링은 닫힌 식 계단 응답으로, 목표가 여러 번 바뀌는 값은 바뀔 때마다 스프링 하나씩을 더해서 시간 t만의 함수가 되게. 오버슈트는 아주 작게.
CSS 트랜지션·타이머 없이, 하나의 paused GSAP 타임라인에서 매 프레임 t로 모든 스타일을 계산해 어느 시점을 렌더해도 같은 화면이 나오게.
```

### 링 12개 탈출 — 결정론적 물리 시뮬레이션 (12초)
```
공이 회전하는 링 12개를 하나씩 뚫고 탈출하는 물리 시뮬레이션 모션을 HTML 캔버스 + GSAP로 만들어줘. 캔버스 1080×830, 12초.
- 짙은 차콜 #0A0A0A 배경, 가운데에 얇은 흰 동심원 링 12개(반지름 66px부터 22px 간격). 링마다 69°쯤 열린 틈이 있고, 안쪽부터 번갈아 반대 방향으로 초당 2.2~2.8 라디안 회전한다.
- 위에 큰 질문 "12개, 다 뚫을 수 있을까?"(Pretendard 600), 왼쪽 위 모노 라벨 "남은 링 12 / 12"가 링이 깨질 때마다 줄어든다.
- 라임 #D4F527 공(반지름 9px)이 중력을 받아 가장 안쪽 링 안에서 튕긴다. 링에 닿을 때 그 지점이 틈이면 통과하고, 아니면 반사한다(튕길 때 속도가 줄어 멈추지 않도록 최소 속도를 보정).
- 통과하는 순간 그 링은 조각난 호 22개로 깨져 바깥으로 날아가며 떨어지고 1초 동안 사라진다. 통과 지점에 라임 파문 하나. 바깥 링으로 갈수록 공이 더 크게 튄다.
- 고정 시드로 시뮬레이션해서 약 10초 안에 12개를 모두 뚫게 맞추고, 마지막에 질문이 사라지며 "하나씩 뚫으면 됩니다"가 떠오른다.
지금 막고 있는 링만 밝게, 나머지는 흐리게. 라임은 공과 파문뿐. 시뮬레이션은 처음에 480Hz 고정 간격으로 끝까지 한 번 계산해 위치를 저장하고, 시간 t의 프레임은 저장한 값을 읽어 그린다. 하나의 paused GSAP 타임라인으로 아무 시점이나 같은 화면이 나오게.
```

### 글자를 그리는 오실로스코프 — 형광 빔 XY 트레이스 (11초)
```
오실로스코프의 형광 빔이 사인파 → 구형파 → 리사주 도형을 거쳐 한글 단어를 그리는 모션을 HTML 캔버스 + GSAP로 만들어줘. 캔버스 1080×830, 11초.
- 짙은 차콜 #0A0A0A 배경, 가운데 880×560 화면에 10×8 칸의 아주 흐린 눈금과 가운데 축의 작은 눈금. 위 모서리에 작은 모노 라벨("CH1 · 2.00 V/DIV · 5 MS/DIV", "CHA · PHOSPHOR P31"), 화면 아래에 지금 모드("Y–T · SINE", "Y–T · SQUARE · 13 HARMONICS", "X–Y · LISSAJOUS 3 : 2", "X–Y · TEXT")와 시간 표시가 실시간으로 바뀐다.
- 빔은 라임 #D4F527 하나. 최근 0.55초 동안 지나간 자리를 머리 쪽이 가장 밝게, 꼬리로 갈수록 지수적으로 흐려지게 그리고, 넓고 흐린 선·중간 선·가는 심 세 겹으로 형광 번짐을 낸다. 빔 끝에는 밝은 점.
- 0–2.6초: 왼쪽에서 오른쪽으로 쓸고 지나가는 사인파. 2.6–4.6초: 홀수 배음을 0.15초마다 하나씩 더해 구형파가 되어 간다(모서리의 출렁임까지 보이게). 4.6초쯤: X–Y 모드로 넘어가 천천히 도는 3:2 리사주 도형.
- 5초부터: "실행"(Pretendard 600)을 화면 밖 캔버스에 그려 글자 테두리 픽셀을 3px 간격으로 뽑고, 가장 왼쪽 점부터 가장 가까운 점으로 이어 하나의 빔 경로를 만든다. 멀리 건너뛰는 구간은 빔을 끈다. 리사주의 각 점이 같은 순번의 글자 점으로 미끄러지며 모양이 바뀐다.
- 처음 한 바퀴는 천천히 글자를 써 내려가고, 이어 빔이 빨라져 단어 전체가 계속 빛난다. 8.9초에 아래 "생각이 파형이라면, 실행은 글자입니다"가 떠오른다.
빔 위치는 시간 t만의 함수로 계산해서 하나의 paused GSAP 타임라인으로 아무 시점이나 같은 화면이 나오게. 라임은 빔뿐.
```

### 마커 메모와 튀는 공 — 종이에서 잉크로 (12초)
```
종이 위 보고서에 마커 메모가 그려지고, 라임색 공이 메모 사이를 튀어 다니다가 검은 화면의 큰 문장 끝에 마침표로 내려앉는 모션을 HTML + SVG + GSAP로 만들어줘. 캔버스 1080×830, 12초, 무음.
- 0–1초: 따뜻한 종이색 #F4F3EE 배경. 왼쪽에 흰 카드("WEEKLY REPORT · W42", 제목 "이번 주 업무 정리")가 살짝 기울어진 채 아래에서 올라와 조금 지나쳤다가 제자리에 선다. 카드 안 네 줄: "회의록 정리 6시간", "보고서 초안 4시간", "데이터 취합 3시간", "최종 결정 1시간"(시간은 회색 모노 글꼴).
- 1–5초: 검은 마커 선이 손으로 그린 듯 그려진다(고정 시드로 살짝 흔들린 곡선, stroke-dashoffset). 1줄에는 느슨한 동그라미 + 화살표 + 메모 "AI면 10분", 2줄에는 두 번 긋는 밑줄 + 화살표 + "초안도 맡기기", 4줄에는 체크 표시 + 화살표 + "나는 판단만". 메모 글자는 윤곽선이 먼저 그려지고 그다음 속이 채워진다.
- 라임 #D4F527 공(화면의 유일한 라임)이 위에서 떨어져 첫 메모 위에 앉고, 메모에서 메모로 포물선을 그리며 뛴다. 착지할 때 납작해졌다 튀어 오르고(스쿼시), 뛰기 직전 살짝 웅크리고, 날아가는 동안 속도 방향으로 길쭉해지며(스미어) 뒤에 옅은 잔상 4개가 따라온다(오니언 스킨).
- 5.7초: 1·2줄의 시간에 마커 취소선이 그어지고 그 줄이 흐려진다. 공은 한 번 제자리에서 튀고 6.6초에 화면 위로 날아간다.
- 7.4초: 하드 컷으로 짙은 차콜 #0A0A0A. 아주 큰 두 줄 "메모는 남기고"(회색), "일은 AI에게"(흰색)가 글자마다 아래에서 튀어 올라온다. 공이 위에서 떨어져 둘째 줄 끝의 마침표 자리에 착지해 두 번 작게 튀고 멈춘다.
- 9.5초: 둘째 줄 아래에 회색 마커 밑줄이 그려지고, 아래쪽에 작은 모노 라벨("CHA · MARKER NOTES", "PAPER → INK · ONE BALL")이 나온다. 종이 장면과 잉크 장면 모두 아주 천천히 줌인해서 정지한 프레임이 없게.
공의 위치·찌그러짐·잔상, 선이 그려진 정도를 전부 시간 t 하나로 계산하는 함수로 만들고(랜덤·타이머·onUpdate 없이), 하나의 paused GSAP 타임라인에서 그 함수를 매 프레임 불러서 아무 시점이나 같은 화면이 나오게. 글꼴은 Pretendard 굵기 500–600, 라벨은 Geist Mono.
```

### 문장이 집이 된다 — 단어로 짓는 건축 타이포 (12초)
```
문장 속 단어가 하나씩 빠져나와 건물의 부재가 되는 타이포그래피 모션을 HTML 캔버스 + GSAP로 만들어줘. 캔버스 1080×830, 12초, 소리 없음.
- 짙은 차콜 #0A0A0A 배경. 위 모서리에 작은 모노 라벨("CHA · WORDS AS STRUCTURE", "LINE 01 / 05").
- 왼쪽 위(46px, Pretendard 500)에 다섯 문장이 차례로 단어 단위로 떠오르고, 다음 문장 직전에 위로 사라진다: "처음엔 아무것도 없었다" → "기록 하나가 바닥이 됐다" → "실패가 기둥을 세웠고" → "질문이 창을 냈다" → "이제 그 위에 선다".
- 0.5초: 화면 아래쪽에 라임 #D4F527 가로선 하나가 가운데에서 양옆으로 그어진다(땅). 라임은 이 선 하나뿐.
- 각 문장에서 단어 하나가 문장 자리를 떠나(자리에는 흐린 회색 글자가 남는다) 음절 하나씩 살짝 호를 그리며 날아가 건물이 된다. 글자는 늘리거나 눕히지 않아서 끝까지 읽힌다. 글자가 자리에 닿으면 그 둘레로 종이색 #F4F3EE 부재가 자라나고, 글자는 그 안에서 차콜색으로 뚫린 글자가 된다(굵기 600).
  - "기록": 두 음절이 가로로 넓게 놓이고 화면 폭 거의 전부(약 860×120)의 바닥판이 자라난다. 라임 선이 바닥판 윗면으로 올라간다.
  - "실패": 두 번 날아가 바닥 양끝에 세로로 "실" 위에 "패"를 쌓은 기둥(약 116×220) 두 개가 된다.
  - "질문": 두 기둥 위에 가로보로 얹히고, 그 아래 열린 공간 안쪽에 가는 회색 문틀(세 변)이 그려진다.
  - "선다": 큰 글자(150px)로 창 안에 떨어져 바닥판 위에 착지한다. 착지할 때 살짝 납작해졌다가 돌아온다.
- 2.4초부터 끝까지 바닥 쪽을 기준으로 아주 천천히 5% 다가간다. 마지막 1.5초는 완성된 건물을 유지.
움직임은 expo 계열로 부드럽게 이어지고, 모든 그림은 시간 t만으로 계산해서 하나의 paused GSAP 타임라인으로 아무 시점이나 같은 화면이 나오게.
```

### 판이 맞는 순간 — 2도 리소그래프 인쇄 (10초) · 원문 일부만 확보, 요약
