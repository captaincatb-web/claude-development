# 모션 용어 21 + 조합 4 — 숫자로 정한 기본값

용어를 "느낌"이 아니라 **값**으로 쓴다. 30fps 기준. 아래 값에서 시작해 콘택트 시트로 확인하며 조정한다.
엔진 함수는 `templates/scene.html`의 `M.*`.

## 기본 타이밍 표

| 동작 | 길이 | 이징 |
|---|---|---|
| 작은 UI 요소 등장 (칩·버튼·아이콘) | 0.25–0.35s | `outCubic` |
| 큰 텍스트·카드 등장 | 0.5–0.8s | `outExpo` |
| 화면 밖으로 퇴장 | 등장의 60–70% | `inCubic` |
| 위치 이동(화면 안→안) | 0.6–0.9s | `inOutCubic` |
| 카메라 푸시/풀 | 1.5–3s | `inOutQuad` (느리게, 끝까지 움직임 유지) |
| 홀드(읽는 시간) | 한글 1초당 약 8–10자, 최소 0.8s | 정지 |
| 스태거 간격 | 글자 0.025–0.04s / 단어 0.06–0.09s / 카드 0.08–0.12s | — |

## 21개 용어

| # | 용어 | 정의 | 구현 기본값 |
|---|---|---|---|
| 01 | 이징 Easing | 일정 속도가 아닌 가감속 | 등장 `outExpo`, 퇴장 `inCubic`, 이동 `inOutCubic`. `linear`는 회전·스크롤 루프·진행 바에만 |
| 02 | 예비동작 Anticipation | 큰 동작 직전 반대 방향으로 살짝 | 본 동작 거리의 8–12%를 0.12–0.18s 동안 역방향 → 본 동작. `inBack`으로 한 번에 가능 |
| 03 | 스쿼시 & 스트레치 | 충돌 시 눌림, 가속 시 늘어남 | 부피 보존: `scaleY = 1+s, scaleX = 1/(1+s)`. 착지 s=−0.25, 최고속 s=+0.15, 복원 0.12s `outBack` |
| 04 | 아크 Arc | 직선이 아닌 포물선 경로 | x는 `linear`/`inOutQuad`, y는 `outQuad`(상승)→`inQuad`(하강)로 분리 계산 |
| 05 | 팔로스루 Follow-through | 본체가 멈춰도 끝부분이 늦게 멈춤 | 자식 요소에 0.06–0.1s 지연 + `spring(k, 6, 1.5)` |
| 06 | 오버랩 Overlap | 부위별 시간차 | 같은 동작을 레이어별로 0.04–0.08s씩 밀어 시작 |
| 07 | 스태거 Stagger | 여러 요소 순차 등장 | `start = base + i * gap`. 개수 많으면 총 길이를 0.6s 안에 맞추도록 gap 축소 |
| 08 | 매치컷 Match cut | 같은 형태로 장면을 잇기 | A의 마지막 형태(원·사각형·선)의 위치·크기를 B 첫 프레임과 **픽셀 단위로 일치** |
| 09 | 패럴랙스 Parallax | 거리별 속도 차 | 배경 0.3×, 중경 0.6×, 전경 1×, 최전경 1.4× 이동 |
| 10 | 마스크 리빌 Mask reveal | 가려졌다 드러남 | 부모 `overflow:hidden` + 자식 `translateY(110%→0)` `outExpo` 0.6s. 또는 `clip-path: inset()` |
| 11 | 모션 블러 Motion blur | 빠른 움직임의 잔상 | 이동 속도 비례 `filter: blur(px)` 방향성은 `scaleX` 늘림(1.0→1.15)으로 흉내. 최고속 프레임에만 |
| 12 | 홀드 Hold | 잠깐 멈춤 | 핵심 메시지 직후 0.8–1.5s 정지. 완전 정지가 어색하면 1–2px 미세 드리프트 |
| 13 | 세컨더리 액션 | 주 동작을 돕는 작은 움직임 | 주 동작 진폭의 10–20%, 빈도는 다르게(예: 깜빡임, 그림자, 파티클) |
| 14 | 줌 스루 Zoom through | 확대하며 장면 전환 | `scale` 1→8 `inExpo` 0.5s, 중간(scale≈3)에서 다음 장면으로 교체 + 다음 장면 0.6→1 |
| 15 | 휩 팬 Whip pan | 휙 넘기는 전환 | 0.25–0.35s, `inOutExpo`, 최고속 구간 블러 12–24px |
| 16 | 아이리스 Iris | 원형으로 열고 닫힘 | `clip-path: circle(r at x y)` r: 0→화면 대각선, `inOutCubic` 0.6s |
| 17 | 키네틱 타이포 | 글자 자체의 움직임 | `M.split()` 후 글자별 y·opacity·rotate 스태거, 한 줄에 동작 1종만 |
| 18 | 카운트업 Count-up | 숫자 증가 | `Math.round(lerp(0, N, outExpo(k)))`, 1.0–1.5s, `font-variant-numeric: tabular-nums` 필수 |
| 19 | 푸시 인 Push in | 카메라가 천천히 접근 | 장면 내내 scale 1→1.06–1.12 `inOutQuad`. 멈추지 않는 것이 핵심 |
| 20 | 비트 싱크 Beat sync | 박자에 맞춰 움직임 | BPM→`beat = 60/BPM`. 컷·등장은 비트 정각, 홀드는 비트 정수배 |
| 21 | 루프 Loop | 끝과 처음 연결 | t=duration 상태 == t=0 상태 (`--check-loop`로 검증). 커서 위치·속도까지 일치 |

## 조합 4종 (기법 쌓기 예)

1. **타이틀 등장** = 키네틱 타이포 + 마스크 리빌 + 스태거 + 이징
   줄마다 마스크, 글자 0.03s 스태거, `outExpo` 0.7s, 끝나고 홀드 1s.
2. **카드 넘기기** = 예비동작 + 휩 팬 + 모션 블러 + 오버랩
   카드가 +12px 뒤로 당겼다가(0.15s) −1200px로 휩(0.3s, 블러), 다음 카드가 0.06s 늦게 진입.
3. **숫자 강조** = 푸시 인 + 카운트업 + 비트 싱크 + 홀드
   카운트가 비트 정각에 끝나고 그 순간 scale 1→1.04 펀치, 이후 1.2s 홀드 동안 푸시 인 계속.
4. **통통 튀는 등장** = 아크 + 스쿼시&스트레치 + 팔로스루 + 세컨더리 액션
   아크로 낙하 → 착지 스쿼시 → 라벨이 0.08s 늦게 스프링 → 바닥 그림자 크기 변화.

## 원문에서 자주 쓰인 추가 기법

| 기법 | 기본값 |
|---|---|
| 스미어 Smear | 속도 방향으로 늘이기 `scale(1+s, 1/(1+s))`, s = min(속도/2400, 0.5) |
| 오니언 스킨 | 0.025s 간격 잔상 4개, 불투명도 0.25→0 |
| 오버슈트 착지 | 목표를 4–8% 지나쳤다 복귀 (`outBack` s=1.2 또는 `springTo` zeta 0.7) |
| 블러 스왑 | 내용 교체 0.18s, 중간에 blur 8px 피크 |
| 하드 컷 | 장면 전환에 컷을 쓰면 새 장면은 첫 프레임부터 이미 움직이는 중 |
| 포커스 디밍 | 현재 대상 불투명도 0.95, 나머지 0.16–0.25 |
| 닫힌 식 스프링 | freq 2–4Hz, zeta 0.6–0.8 (오버슈트 아주 작게) |
| 끝없는 드리프트 | 전체 그룹 18px/장면 또는 scale 1→1.03–1.05 |

## 좋은 모션의 판정 기준

- **한 번에 하나만 본다**: 같은 순간 큰 동작은 하나. 나머지는 정지 또는 세컨더리 수준.
- **원인 → 결과**: 커서가 누른다 → 화면이 바뀐다. 결과만 갑자기 나타나지 않게.
- **연속성**: 장면 사이를 하드컷보다 형태·위치·색으로 잇는다(매치컷, 모프).
- **결과가 보이는 순간**을 가장 크게, 가장 오래 보여 준다.
