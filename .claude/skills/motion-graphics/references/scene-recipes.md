# 장면 레시피 — CHA Motion Kit 172 분석

참고: careerhackeralex.com/sharings/cha-motion-kit (172개, 2026.10). 카테고리별로 **언제 쓰는지 → 비트 구성 → 핵심 기법**만 추린 것. 원작 코드·문구는 쓰지 않고 구조만 참고한다.

공통 규칙(키트 전체에서 반복되는 패턴)
- 인서트는 1080×830·30fps·무음, 대부분 **4–7.5초**. 대사가 "~하면 됩니다"라고 말한 **직후** 5–6초 삽입.
- 장면 하나 = **원인 → 결과 하나**. 결과가 보이는 순간을 가장 크게.
- 실제 앱/AI 결과는 재연하지 말고 **녹화·이미지 슬롯**으로 비워 둔다(`<img data-slot>`/`<video data-slot>`).
- 문구·변수(색, 숫자, 단어 목록)는 장면 상단 `CONFIG` 객체로 빼서 바꾸면 같은 규칙으로 재계산되게.

## A. 타이포그래피 (23) — 글자가 메시지를 전함 · 3–5.6초

| 레시피 | 비트 | 핵심 |
|---|---|---|
| 바에서 솟아오르는 워드 | 바 그려짐 → 단어가 바 위로 마스크 리빌 → 홀드 | 바 = 마스크 경계, `outExpo` |
| 비트 스퀘어 문장 빌드 | 비트마다 정사각 블록 + 단어 하나 추가 | BPM 그리드, 블록 색 교차 |
| 뷰파인더 비트 워드 슬램 | 카메라 뷰파인더 코너 안에 단어가 비트마다 하드컷 | scale 1.15→1 펀치 0.12s |
| 두 줄 헤드라인 + 형광펜 | 2줄 리빌 → 핵심 구절 형광펜 좌→우 | 형광펜 `scaleX` 0→1, 텍스트 뒤 |
| 읽는 만큼 채워지는 자막 | 회색 문장 → 읽는 속도로 글자색 채움 → 키워드만 강조색 | 글자당 0.06s |
| 라벨 박스 워드 → 한글 문장 | 영문 라벨 박스들이 모여 한글 문장으로 | FLIP 이동 |
| 글자 안에서 움직이는 도형 | 큰 글자를 마스크로, 안에서 도형·이미지 이동 | `background-clip:text` 또는 SVG mask |
| 로고 스팅 (3초) | 렌즈 점 → 확장 → 실루엣/로고 → 컷 | 매치컷, 정사각/세로 2버전 |
| 믹스 타입 워드마크 | 모노 소문자 + 굵은 대문자 + 강조색 음절 조합 | 서체 대비 |
| 같은 자리 문구 스택 | 한 자리에서 문구가 위로 밀려 교체 ×3 | 퇴장 끝-등장 시작 간격 확보 |
| 픽셀 네임 플레이트 | 픽셀 격자가 순서대로 채워져 이름 | 시드 랜덤 순서 스태거 |
| 에디토리얼 커버 | 가로 레일(선) 위에 헤드라인이 내려앉음 | 선 드로우 → 착지 `outBack` 약하게 |
| 디자인툴 선택 박스 타이포 | 텍스트에 선택 박스·핸들이 붙고 리사이즈 → 굵기/크기 변경 | 툴 UI 은유 |
| 거대한 숫자 롤 | 슬롯처럼 자릿수가 굴러 숫자 → 라벨 → 진행선 | 자릿수별 지연, `tabular-nums` |
| 흩어진 태그 → 한 문장 | 태그 칩이 무작위 위치에서 한 줄로 수렴 | 시드 위치, 0.08s 스태거 |
| 글자가 창이 되는 전환 | 거대 텍스트 마스크 안에 다음 장면 → 마스크 확대해 풀프레임 | 줌 스루 + 텍스트 마스크 |
| 레이아웃 그리드 위 조립 | 12컬럼 가이드가 보이고 그 위에 타이포 블록 스냅 | 스냅 시 1px 오버슈트 |
| 숨쉬는 굵기·자간 | 가변 폰트 wght 300↔900, 자간 미세 변화 루프 | `font-variation-settings` |
| 문장 속 한 단어 슬롯 | "나는 ___ 한다" 빈칸만 세로 슬롯 회전 | 단어 폭 보간 |
| 워드 월 + 숫자 펀치 | 회색 단어 벽 → 하나만 강조 → 큰 숫자 펀치 | 홀드 후 펀치 |

## B. 트랜지션 (9) — 장면 잇기 · 4.2–4.8초

| 레시피 | 핵심 |
|---|---|
| 카드 스택 스와이프 ×2 → 다음 장면 | 예비동작 + 휩 + 블러, 뒤 카드 오버랩 |
| 폰이 뒤집히며 다음 화면 | `rotateY` 0→180, 90° 지점에서 내용 교체, perspective |

| 점 → 로고 렌즈 매치컷 | 점이 커져 원형 렌즈 → 렌즈 안이 다음 장면 (아이리스) |
| 풀프레임 → 풀백, 알고 보니 폰 화면 | scale 1→0.35, 주변에 폰 베젤 등장 |
| 랙 포커스 | 앞 카드 blur 0→8px, 뒤 화면 8→0px 교차 |
| 비스듬한 창 3개가 모여 한 화면 | 3D 회전된 창들이 정면으로 합쳐짐 |
| 창 하나 → 3×3 그리드 → 골라 줌인 | 축소 + 그리드 스태거 → 선택 하이라이트 → 줌 스루 |
| 노트북 화면 속으로 줌인 | 화면 영역이 뷰포트를 채울 때까지 `inExpo` 줌 |

## C. 컴포넌트 (17) — 화면 데모 · 5–6.6초

브라우저(주소 입력 → 로딩 바 → 스켈레톤 → 콘텐츠 → 스크롤), 채팅(입력 → 생각 중 점 → 토큰 스트리밍 → 결과 카드), 터미널(명령 → 로그 스트리밍 → DONE), 폰 앱(리스트 탭 → 푸시 → 바텀시트), 피드 관성 스크롤 + 카드 탭 리프트, 잠금화면 알림 스택 → 펼침, 독에서 창 열기 → 캐스케이드 → 타일 정리, 스크린 녹화 오토줌(커서 따라 1.6× 줌·팬·줌아웃), 근무 시계 09:00→18:00, 글로우 채팅/에이전트(한 문장 요청 → 단계 체크 → 완료).
- 토큰 스트리밍: 단어 단위 0.03–0.05s, 커서 블록 끝에 고정.
- 관성 스크롤: 속도 `v *= 0.92` per frame를 시간식으로 → `y = v0/k * (1 - e^{-kt})`.
- 오토줌: 줌 1→1.6 `inOutCubic` 0.6s, 팬은 커서 위치를 0.15s 늦게 추적(팔로스루), 줌아웃 0.5s.

## D. 기법 (20) — 3D·원근·깊이 · 4.6–7초

비트마다 하드컷 한 단어, 노트북+폰 오빗, 노트북 힌지 열림 + 화면 깨어남 + 돌리 + 포커스 풀, 폰 뒷면→앞면 회전, 원형 마스크 화면 + 원형 타이포 회전, **UI 카드 분해도(레이어 익스플로드)**, 폴더 열림 → 카드 부채꼴, **아이소 창 벽 → 하나 들어올리기**, 긴 랜딩 페이지 슬랜트 돌리 → CTA, UI 콜라주 + 대각선 티커 밴드, 모자이크 조립 → 풀백 → 한 칸 포커스, 아웃라인 텍스트 행 배경 + 중앙 카드 교체, **레이어 패럴랙스 히어로**, **화면 속 화면 무한 줌(드로스테 루프)**, 대시보드 스포트라이트 리프트, 휩 팬 + 스피드 램프.
- 레이어 익스플로드: 레이어별 `translateZ(i*80px)` + `rotateX(55) rotateZ(-30)` 기울기 → 다시 합침.
- 드로스테: 화면 안에 같은 장면을 0.25배로 재귀 3단 배치, scale을 4배까지 키우면 처음과 동일 → 완벽 루프.
- 스피드 램프: 시간 재매핑 `t' = kf(t, [[0,0],[1,0.4,'outCubic'],[1.3,1.6,'inExpo'],[2,2]])`.

## E. 화면 속 작업 (20) — 조작의 원인과 결과 · 6–6.5초

명령 한 줄로 장면 열기 · 댓글 → 수정 완료 · 인스턴스 분리 후 하나만 수정 · 이미지 드래그 적용 · 입력이 대시보드로 · 같은 이미지에서 주인공 찾기(리프레임) · 캔버스 가로질러 완성 · 슬라이더가 화면을 바꿈 · 단축키 3개 연속 · 핸드오프 · 노드 연결 → 흐름 실행 · 폭이 바뀌면 구조 변경(반응형) · 스크롤 후 핵심에서 멈춤 · 타임라인 정밀 탐색 · 검색 → 답 · 다중 선택 일괄 편집 · 코드 → 실시간 미리보기 · 탭 전환해도 맥락 유지 · 필터 → 정렬 · 이전 버전 복원.
- 구조: **커서 진입(0.6s) → 조작(1.5–2s) → 결과 변화(1s) → 결과 홀드(1.5s+)**.
- 커서·키캡 오버레이로 "무엇을 눌렀는지" 표시(키캡은 누를 때 y+3px, 그림자 축소).

## F. 창작 변환 (21) — 프롬프트 → 이미지 → 움직임 → 타이포 · 6.8초 (+16.8초 풀버전)

말소리 → 문장 · 아홉 컷 중 베스트 선택 · 윤곽선 → 로고 면 · 아웃페인트(캔버스 확장) · 이미지가 글자 표면 · 평면 이미지 레이어 펼치기 · 글자가 열리면 장면 시작 · 부분 수정(인페인트) · 긴 설명 → 핵심 · 한 문장 → 시안 4장 · 요청 → 화면 구조 · 낙서 → 제품 시안 · 정지 → 움직임 · 형태/질감 따로 참고 · 곡선 타고 문장 · 문장 → 벡터 · 타임라인 → 장면 계획 · 텍스트 토큰이 그림 재료 · 키워드 → 작업 화면 · 글자 깊이 접기.
- 결과 이미지는 **슬롯**(사용자 파일). 슬롯이 비면 단색 플레이스홀더 + 라벨.
- 16.8초 풀버전은 의미 단위로 잘라 쓸 수 있게 구간 경계(예: 0–5.8 / 5.95–10.1 / 10.5–16.8)에서 짧은 홀드.

## G. 녹화·설명 (20) — 내 녹화를 확대·비교 · 5.2–7.4초

같은 단계끼리 나란히 비교 · 원문 → 핵심 문장 · 한 결과 세 포맷 · 기준표로 우선순위 · 시간 절감 지점 · Q&A 하나씩 · 세 시야(전체/중간/디테일) · 작업 흐름 다이어그램 · 반복 구간 빠르게/결과는 원속 · 조건 분기 · 녹화 따라 세 곳 짚기 · 확대하면서 미니맵 · 조작 경로 표시 · 먼저 짚고 재생 · 맥락+디테일 PiP · 입력 → 실행 가로 배치 · 가로 녹화를 세로로 리프레임 · 리플레이 · 중요 순간 클로즈업 · 필요한 세 구간만.
- 녹화 슬롯 `<video data-slot>`는 `__seek`에서 `currentTime` 동기화.
- 미니맵: 우상단 20% 축소본 + 현재 보는 영역 사각형.

## I. 제너레이티브 (5) · 8초 / 리믹스 (7) · 10–12초 — 규칙으로 자라는 장면

| 장면 | 규칙 |
|---|---|
| 공을 피해 다시 흐르는 문단 | 줄마다 공과 겹치는 x 구간을 빼고 텍스트 재배치(매 프레임 레이아웃 계산) |
| 한글 ASCII → 디더 → 셰이딩 3분할 | 같은 3D 형상을 문자/디더/셰이딩 3가지로 렌더 |
| 점균(피자룸) 4만 에이전트 | Physarum: 센서 각도·거리, 트레일 확산·감쇠 (canvas, 고정 스텝) |
| 리퀴드 글래스 | SDF 메타볼 두 개 smooth-min 합체 + 굴절 (WebGL) |
| 글자 안에서 자라는 산호 | Gray-Scott 반응-확산, 글자 마스크 안에서만 |
| 끊기지 않는 도형 → UI 10단 모프 | 하나의 사각형이 width/height/radius/색 보간으로 버튼→토글→카드→… 연속 변환. 내부 텍스트는 별도 타이밍 |
| 토큰 버킷 시뮬레이션 | 버킷 용량·리필 속도·요청 도착을 데이터로 시뮬 → "한도 도달" 상태 시각화 |
| 링 12개 탈출 (결정론적 물리) | 동심원 링의 틈을 찾아 공이 하나씩 깨고 나감. 고정 스텝 물리 |
| 오실로스코프 글자 | 글자 윤곽 경로를 XY 신호로 → 형광 빔 잔광(이전 프레임 알파 누적) |
| 2도 리소 인쇄 | 두 색 판이 어긋났다가 맞으며 또렷해짐 + 그레인 |
| 마커 메모 위 튀는 공 | 종이 질감 위 손글씨 메모를 공이 짚고 → 다크 전환 결론 |
| 단어로 짓는 건축 | 단어 블록이 쌓여 건물 실루엣 → 사람 |

시뮬레이션은 항상: **시드 고정 · 고정 스텝 · t=0부터 재계산(또는 프레임 캐시)**.

## J. 필름 (5) — 세로 광고·데모 · 13–16초 · 1080×1920

원테이크 심리스(점 → 앱 → 폰 → 노트북 → 창의 벽 → 한 줄 → 로고)처럼 **컷 없이 형태로 잇는** 구성. 각 구간 2–3초, 경계는 매치컷/줌 스루. 마지막 2초 로고 엔드카드 홀드.
