# 스타일 시스템 — 포맷 · 팔레트 · 타이포 · 레이아웃

## 1. 포맷

| 용도 | 크기 | 비고 |
|---|---|---|
| **숏츠 인서트 (기본)** | 1080×830 · 30fps · 무음 | 9:16 화면의 가운데 블록. 위는 채널 헤더, 아래는 외부 자막 영역으로 비워 둔다 |
| 세로 풀스크린 (광고·엔드카드·필름) | 1080×1920 · 30fps | 하단 18%와 우측 120px는 플랫폼 UI(좋아요·캡션)에 가려짐 |
| 가로 (유튜브 본편·발표) | 1920×1080 · 30fps | |
| 정사각 (피드) | 1080×1080 | |

길이: 인서트 4–7.5초, 개념 시뮬레이션·리믹스 8–12초, 필름 13–16초. **대사 한 문장 = 한 장면**이 기준.

### 안전 영역
- 바깥 여백: 가로 80px / 세로 64px (1080 폭 기준). 핵심 텍스트는 이 안에.
- 1080×1920: 위 220px, 아래 360px, 오른쪽 140px 안에 핵심 요소 금지.
- 자막은 장면 안에 넣지 않는다(외부 캡션과 겹침). 장면 내 텍스트는 **헤드라인·라벨·UI 문구**만.

## 2. 팔레트 프리셋

토큰은 `:root`에 정의하고 장면 코드에서는 `var(--*)`만 쓴다. 강조색은 **한 장면에 하나**.
`templates/scene.html`의 기본값은 INK-LIME. 다른 프리셋은 SCENE STYLES 맨 위에 `:root { … }`를 덮어쓴다 (예: `examples/code-to-video.html`의 INK-CORAL).

### INK-LIME (다크 · 기본) — CHA Motion Kit 원문 규칙
```
--bg:#0A0A0A (짙은 차콜)  --surface:#161616  --line:#262626
--ink:#ffffff  --muted:#8c8c8c (회색 UI·모노 라벨)
--accent:#D4F527 (라임 — 화면 전체에서 딱 한 곳)  --danger:#ff4d4d (거절·오류 상태색만)
```
폰트 Geist(영문)/Pretendard(한글) 400–600. 위쪽 두 모서리에 작은 회색 모노 라벨 (`CHA · 128 BPM` / `03 THINGS`).

### INK-CORAL (다크) — 카드뉴스 톤
```
--bg:#111111  --surface:#1b1b1b  --line:#2c2c2c
--ink:#f2ede4 (크림 화이트)  --muted:#8a857c
--accent:#ff5a36 (코랄 오렌지)  --accent-2:#c6ff3d (라임, 보조 하이라이트만)
```
배경에 36px 점 그리드(불투명도 7%).

### PAPER (라이트 · 에디토리얼)
```
--bg:#f4f1ea  --surface:#ffffff  --line:#d9d4c9
--ink:#151515  --muted:#6f6a61  --accent:#c6ff3d (라임 형광펜)  --accent-2:#ff5a36
```
라임은 글자색이 아니라 **형광펜 배경**(`linear-gradient` 하단 40%)으로.

### SPLIT (잉크 | 페이퍼 | 라임 블록)
화면을 2–3개의 색 블록으로 분할하고 경계에서 전환. 메시지 대비·전후 비교에 사용.

### GLOW (프리미엄 · 테크)
```
--bg:#07080b  --ink:#eef1ff  --accent:#7c8cff  --accent-2:#62f5d0
```
블러된 컬러 블롭(`filter: blur(80px)`) 2–3개를 느리게 이동 + 글래스 카드(`backdrop-filter` 대신 반투명 + 1px 하이라이트 보더 — 렌더 안정성).

## 3. 타이포그래피

- 서체: 영문 **Geist**, 한글 **Pretendard Variable**, 라벨·숫자 **Geist Mono** — 템플릿에 `@font-face`로 선언됨(jsdelivr npm URL). 렌더러가 오프라인에서 npm 사본으로 대체하므로 별도 설치 불필요.
- 원문 규칙: 굵기 400–600이 기본(과한 900은 히어로 단어에만).
- 스케일 (1080 폭 기준)

| 역할 | 크기 | 굵기 | 자간 / 행간 |
|---|---|---|---|
| 히어로 단어 | 200–320px | 900 | −0.04em / 0.95 |
| 헤드라인 | 96–130px | 800 | −0.03em / 1.05 |
| 서브 헤드 | 56–72px | 700 | −0.02em / 1.15 |
| 본문 | 34–42px | 500 | −0.01em / 1.5 |
| 라벨·캡션(모노) | 22–28px | 500 | +0.04em, 대문자/작은 글씨 |

- 한 화면 텍스트는 **헤드라인 1 + 보조 1–2줄**까지. 넘치면 장면을 쪼갠다.
- 2색 헤드라인: 앞 구절 `--ink`, 핵심 구절 `--accent` (예: "복사해서 **세 단계**").
- 줄바꿈은 의미 단위로 직접 `<br>`. 한글 단어 중간이 끊기지 않게 `word-break: keep-all`.

## 4. 반복 요소 (브랜드 일관성)

- 상단 바: 왼쪽 필 라벨(● 카테고리) · 오른쪽 브랜드 마크 — 시리즈물에서만.
- 섹션 키커: `$ 정리`, `01 · prompt-motion.com` 같은 모노/작은 라벨 → 헤드라인.
- 번호 박스: 코랄 정사각형 안의 숫자 + 굵은 단계명 + 회색 설명 (단계 설명 장면).
- 구분선: 1–2px `--ink` 또는 `--line`, 왼쪽→오른쪽으로 그려지며 등장.
- 브라우저 프레임: 신호등 3점 + 주소 바(모노), 하단 2px 코랄 라인 — 스크린 캡처를 넣을 때.

## 5. 깊이와 3D (CSS만으로)

- 부모에 `perspective: 1600px`, 자식에 `transform: rotateX/rotateY/translateZ`.
- 아이소 창 벽: `rotateX(55deg) rotateZ(-45deg)` 기준.
- 그림자는 두 겹: 가까운 진한 그림자 + 먼 흐린 그림자. 깊이가 바뀌면 그림자도 함께 보간.
- 진짜 3D(디바이스 목업·재질)가 필요하면 Three.js(CDN) 캔버스를 쓰되, 시간은 반드시 `render(t)`에서 받는다.
